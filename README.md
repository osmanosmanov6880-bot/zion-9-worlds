# ZION-9 Infinite Worlds

A public, static archive of ten interactive narrative prototypes.

- **Live site:** [GitHub Pages](https://osmanosmanov6880-bot.github.io/zion-9-worlds/)
- **Hosting:** GitHub Pages, free static hosting for this public repository.
- **Privacy boundary:** this repository contains only the curated public HTML release. The private source repository, internal runbooks, operator configuration, provider status, and credentials are not copied here.
- **Runtime:** no backend, no paid API, no external script dependency, no analytics or tracking.
- **Publishing:** pushes affecting `public/**` trigger the pinned GitHub Pages workflow.

The worlds are story prototypes, not a production multiplayer service. Do not add secrets or private operator material to this repository.
